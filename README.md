# Edgewood Male Mentoring Program

Responsive, buildless website for a mentoring program serving Black male students at Edgewood High School in Harford County, Maryland.

## Preview
Run `python3 -m http.server 4173 --directory dist` and open http://localhost:4173.

## Contents
- `dist/index.html`: content and semantic structure
- `dist/styles.css`: responsive design
- `dist/app.js`: mobile menu, keyboard-accessible pathway tabs, interest dialogs, downloadable conversation starters
- `dist/assets/mentorship.webp`: conceptual editorial illustration, not actual participants

Program name supplied by the owner. Contact information, application process, schedule, and actual program photographs remain to be supplied. The website does not collect personal data or claim to submit applications. No fabricated testimonials, outcomes, affiliations, or events are included.

Design reference: https://100bmoh.org/ (layout clarity and content hierarchy; original copy, visual identity, and implementation).

## Color palette
Edgewood High School’s red and white inspired palette, with charcoal text and light neutral backgrounds. The chosen digital red (#B51F32) is a design interpretation, not a verified official brand hex code. School colors source: https://www.mpssaa.org/assets/1/6/Class_3A_Girls_BSKB_Semifinal_Media_Forms.pdf
